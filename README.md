# Simulador de Investimentos em Fundos Imobiliários

Projeto educacional em Excel para simular investimentos em FIIs, do aporte mensal ao patrimônio projetado e aos dividendos estimados.

## Funcionalidades
- VF/FV para patrimônio futuro.
- Cenários de 2 a 30 anos.
- Intervalos nomeados.
- PROCV e tabela de apoio por perfil.
- Estimativa de dividendos.
- Gráficos e documentação.

> Premissas ilustrativas para fins educacionais; não constituem recomendação de investimento.
